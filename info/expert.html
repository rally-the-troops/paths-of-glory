Paths of Glory — Expert Mode

This mode automates many player actions to expedite asynchronous games. Players who are less familiar with the rules of the game may find it difficult to follow the flow of the game when these steps are automated, so it is recommended only for expert players who are already familiar with the rules. Automated actions can still be reviewed in the game log.

Choices of which units to lose in combat will be automated when all possible choices result in the same outcome.

The attrition and siege phases at the end of the turn are fully automated.

When playing a reinforcement card, units will be automatically placed if there is only one valid location, for example, corps will be automatically sent to the reserve box.
